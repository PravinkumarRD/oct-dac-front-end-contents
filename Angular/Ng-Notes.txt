1) Parent-To-Child - 
	Declare a property in child component and decorate the same property with @Input() metadata and use this property with child component selector with property binding syntax
	For Example - 
		<app-event-details [event]="selectedEvent"></app-event-details>

2) Child-To-Parent - 
	Declare a property in child component with a special type called EventEmitter<T> and decorate this property with @Output() metadata. Fire/Emit the data from the child component by calling emit() method of EventEmitter object which you want to send it to parent component
	Handle the event with event binding syntax of child component selector in which you call the parent component function which will receive the emitted data from the child component as a payload using a very special object called "$event"

	For Example - 
		<app-event-details [event]="selectedEvent" (eventName)="parentFunction($event)"></app-event-details>
